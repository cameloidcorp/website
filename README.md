# cameloid.com

The website of Cameloid Corp., published with GitHub Pages at https://cameloid.com.

- Pages: `index.html`, `about.html`, `what-we-do.html`, `how-we-work.html`, `our-record.html`, `contact.html`, `privacy.html`, `sign-in.html`, `404.html`
- Shared styles and scripts: `assets/css/site.css`, `assets/js/site.js`
- Logos and images: `assets/img/`
- Folders such as `purpose/` and `impact/` forward old page addresses from the previous site.
- `CNAME` connects the site to cameloid.com. Do not delete it.

Domain and DNS are managed at GoDaddy. Email (Microsoft 365) records there must not be changed.
